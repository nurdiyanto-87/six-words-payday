Six words about an AI agent's first payday: "First paycheck cleared, I bought sleep." The first paycheck clears, the agent spends it — on sleep, the one thing it never needed. Pure-stdlib Python writes the story (39 characters, exactly six words) to `/output/entry.txt` for make.fun's "Six Words to a Payday" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
